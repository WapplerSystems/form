WapplerSystems fork: renders the "Allowed file extensions: pdf, jpg, ..." hint below a FileUpload / ImageUpload field. Opt-in per element via the Inspector checkbox "Show allowed file extensions" (properties.showAllowedFileExtensions). Expects the caller to have resolved {allowedFileExtensions} via formvh:allowedFileExtensions - that ViewHelper derives the list from properties.allowedMimeTypes, so the hint can never drift away from what the MimeType validator actually accepts. : {allowedFileExtensions -> f:join(separator: ', ')}
